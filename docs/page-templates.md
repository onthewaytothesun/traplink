# Шаблоны страниц

Раздел **Шаблоны** доступен в верхней навигации и по адресу `/admin/?tab=templates`. В нём есть предустановленные и пользовательские шаблоны, поиск, превью и кнопка **Создать**. Создание сразу открывает редактор новой страницы. Название и адрес можно изменить через настройки страницы.

В обоих редакторах страницы есть **Сохранить как шаблон**. Сохраняется последняя записанная на сервере версия — перед этим нужно сохранить открытый редактор блока. Название и описание шаблона задаются в окне сохранения. Изменение или удаление исходной страницы не меняет сохранённый шаблон.

Копируются блоки, секции, порядок, видимость, якоря и оформление. Новая страница не становится главной. Все ID страниц, секций и блоков новые; ссылки на `/p/исходный-slug` в структурированных настройках направляются на копию. HTML-код не разбирается и не переписывается. Медиафайлы и ссылки на существующие товары остаются общими. Заявки, заказы и платёжные настройки не копируются.

Оформление шаблона применяется только к новой странице. Для изменения нажмите **Дизайн страницы** над превью. Переименование или перенос в папку сохраняет оформление. Глобальный дизайн не перезаписывает оформление, зафиксированное в шаблоне.

Предустановлены: **Личная визитка**, **Услуги специалиста**, **Образовательный курс**, **Портфолио**, **Простая мультиссылка**, **Автор и соцсети**, **Кофейня**. В них демонстрационные тексты, цены и контакты — замените их перед использованием. Каталог расширяется в `includes/page-template-presets.php`.

Пользовательские шаблоны хранятся отдельно в новой таблице `tap_templates`, которая создаётся при первом обращении к API шаблонов. Удаление шаблона не затрагивает созданные страницы. Предустановленные шаблоны неизменяемы.

Создание страницы транзакционное. Токен запроса сохраняется в sessionStorage до успешного ответа: повтор после потери ответа возвращает ту же страницу. Превью запускается в sandbox iframe; HTTP CSP также запрещает выполнение скриптов и отправку форм.

## Проверки

```sh
php tests/page-templates.php
php tests/zero-render.php
node --test tests/zero-model.test.cjs
```

Браузерный тест запускает отдельную временную SQLite-базу и локальный PHP-сервер, не использует рабочую БД:

```sh
TEMPLATE_TEST_ALPINE=/path/to/alpine-cdn.min.js PLAYWRIGHT_PATH=/path/to/playwright node tests/templates-browser.cjs
```

Нужны PHP с PDO SQLite, Google Chrome и Playwright. Проверяются каталог, фактическое содержимое iframe, поиск/фильтры, сохранение своего шаблона, создание, потеря ответа после коммита, безопасный повтор, удаление и мобильная раскладка.

Для новых трёх шаблонов сгенерированы оригинальные фотографии через imagegen. На сайт публикуются JPEG-копии: аватар 512 px, обложки 1200 px. Изображения остальных четырёх шаблонов сохранены из текущей рабочей копии.
