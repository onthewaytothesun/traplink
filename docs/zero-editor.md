# Редактор «Свой блок»

В форме блока типа 51 нажмите **Открыть редактор слоёв**. Добавляйте текст, изображения, кнопки и фигуры. Порядок в списке слева соответствует наложению: верхний слой перекрывает нижние. Кнопки **Выше / Ниже** меняют порядок; рядом с каждым слоем доступны скрытие и блокировка.

На холсте элементы можно перетаскивать и растягивать за угловые маркеры. Справа задаются точные координаты, размеры, оформление и ссылки. Сетка привязывает перемещения к шагу 8 px; её можно отключить. Изображения загружаются через существующий `/admin/upload.php` или задаются URL.

Режимы **Компьютер** (1000 px) и **Телефон** (375 px) имеют независимые координаты, размеры элементов, размеры текста и высоту холста. Содержание, оформление и порядок слоёв общие. На сайте используется мобильная раскладка при ширине контейнера меньше 600 px. Макет пропорционально масштабируется по ширине контейнера.

**Применить** переносит черновик в форму. Затем нажмите **Сохранить** в форме блока, чтобы записать его на сервер. **Отмена** оставляет исходный блок без изменений; при изменённом черновике запрашивается подтверждение. Ошибки сохранения обрабатывает существующая форма.

Клавиши вне текстовых полей:

- Ctrl/⌘ Z — отменить; Ctrl/⌘ Shift Z или Ctrl/⌘ Y — повторить.
- Ctrl/⌘ D — дублировать слой.
- Delete / Backspace — удалить незаблокированный слой.
- Стрелки — сдвиг на 1 px, Shift + стрелки — на 10 px.

## Хранение и совместимость

Документ находится в `options.zero`: версия, параметры desktop/mobile, background и массив layers от заднего плана к переднему. Старые блоки с `options.html` продолжают работать. При создании слоёв старый HTML сохраняется в данных, но отображение переключается на `options.zero`; автоматической конвертации HTML в слои нет.

Новые документы рендерит `includes/zero-render.php`: текст экранируется, CSS формируется из ограниченных свойств, опасные URL исключаются. Предпросмотр и публичная страница используют один рендерер. Сырые HTML-блоки в админке по-прежнему показываются как исходный код.

## Проверки

```sh
node --test tests/zero-model.test.cjs
php tests/zero-render.php
node --check assets/zero-editor.js
```

Браузерный сценарий требует Playwright и установленный Google Chrome:

```sh
node tests/zero-browser.cjs
```

Если Playwright установлен отдельно, задайте `PLAYWRIGHT_PATH` абсолютным путём к его пакету. Тест запускается на изолированной странице, не обращается к рабочей БД, проверяет редактор и PHP-рендеринг. Скриншоты сохраняются в `/tmp/zero-editor-desktop.png` и `/tmp/zero-editor-mobile.png`. Для ручного локального теста есть `tests/zero-editor.html`.

## Файлы для публикации

- `assets/zero-model.js`, `assets/zero-editor.js`, `assets/zero-editor.css`, `assets/zero-public.css`
- `includes/zero-render.php`
- изменённые `admin/index.php`, `admin/page-preview.php`, `admin/render-fragment.php`, `page.php`

Изменения схемы БД не нужны. Перед публикацией общих PHP-файлов учитывайте остальные незакоммиченные изменения в них. Документацию и тестовые страницы публиковать не требуется.
